- **Write clearly** and concisely
- **Use active voice** (I did, not tasks were done)

- Keep it **simple** (clean beats fancy)
- Use **white space** (don't overcrowd)
- Make it **scannable** (recruiters spend 6 seconds)

- Test **mobile first** (most recruiters use phones)

- Deploy **early** (don't over-perfect)

## 🔧 TROUBLESHOOTING

### Portfolio doesn't load
- Make sure `index.html` exists
- Double-click it to open
- Try different browser
- Check file isn't corrupted

### Styles look broken
- Make sure `css/style.css` exists in `css/` folder
- Refresh browser (Ctrl+F5)
- Check browser console (F12)

### Mobile looks weird
- Test on actual device (not just browser)
- Clear browser cache
- Try different browsers
- Check CSS is applied

### Deploy shows error
- Check all files uploaded
- Wait 1-2 minutes for deployment
- Verify file structure matches
