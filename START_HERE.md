## 📞 TROUBLESHOOTING

**Links don't work?**
- Make sure you replaced the actual URL
- Check for typos in links
- Make sure https:// is included

**Mobile looks weird?**
- Test on actual phone, not just browser
- Clear browser cache
- Check in different browsers

**Styles look broken?**
- Make sure style.css is in css/ folder
- Refresh browser (Ctrl+F5)
- Check browser console for errors

**Deploy shows "Not Found"?**
- Wait 1-2 minutes for site to deploy
- Make sure all files uploaded correctly
- Clear browser cache
